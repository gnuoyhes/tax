# 예상 세액 계산 검산표

세액 또는 대안별 부담을 제시할 때마다 이 표를 복사해 채운다. 공제액·세율·누진공제·세액공제율은 기억으로 입력하지 말고, 적용 기준일의 공식 근거를 셀 단위로 연결한다.

- 사건 ID:
- 과세 기준일:
- 계산 버전:
- 사건 입력 버전:
- 법률 파라미터 세트 ID:

## E. 독립 재검산

- [ ] 모든 금액 단위가 원/천원/백만원 중 하나로 통일되었다.
- [ ] 표의 합계와 본문의 금액이 일치한다.
- [ ] 구간별 세율 방식과 누진공제 방식이 같은 결과를 낸다.
- [ ] 코드 또는 스프레드시트로 산식을 독립 재계산했다.
- [ ] 음수 과세표준, 한도 초과 공제, 중복 공제를 점검했다.
- [ ] 세액공제 적용 순서와 한도를 확인했다.
- [ ] 법정기한과 휴일 이월 여부를 공식 자료로 확인했다.
- [ ] 불확실한 법률 입력을 숫자 정확도로 위장하지 않았다.
- [ ] 신고세액과 별도 세금·비용을 섞지 않았다.

## F. 계산 메모

재검산 도구, 파일명 또는 코드, 실행일, 검토자, 발견된 차이와 해결 내용을 기록한다. 결과가 다르면 더 보수적인 숫자를 택하지 말고 차이 원인을 먼저 해결한다.
