# 증여 사건 초기 상담 체크리스트

새 증여 사건의 계산 또는 구조 비교 전에 사용한다. 각 항목은 `확인 / 미확인 / 해당 없음`으로 표시하고, 근거 문서와 기준일을 적는다.

- 사건 ID:
- 과세 기준일(실제/예정 증여일):
- 접수일과 담당자:
- 현재 사건 상태:

## 1. 기본 정보

- 검토 국가, 증여 예정일 또는 실제 증여일, 검토 기준일
- 증여자·수증자의 세법상 거주자 여부, 국적, 주소지 국가
- 당사자 관계, 수증자 나이, 세대생략 여부
- 증여의 목적과 원하는 실행 시점
- 이미 체결·이행된 계약, 등기, 송금, 채무인수 여부

## 2. 재산과 평가

- 재산 종류: 현금 / 예금 / 부동산 / 상장주식 / 비상장주식 / 보험 / 신탁 / 기타
- 소재지, 권리자, 공유지분, 평가기준일
- 사용자가 말한 금액과 그 근거: 거래가, 감정가, 기준시가, 시세, 재무제표 등
- 취득일, 취득가액, 자본적 지출, 보유기간
- 임대차보증금, 담보대출, 기타 채무와 실제 상환자
- 처분 제한, 질권, 신탁, 수익자 지정, 분쟁 또는 명의 불일치

## 3. 과거 거래

- 증여자별 최근 증여 내역: 날짜, 재산, 신고가액, 세액, 신고 여부
- 동일 가족 간 차용·상환·생활비·교육비·보험료 부담 내역
- 자금 원천과 계좌 흐름, 현금 사용 사유
- 과거 평가·신고에 대한 세무서 문의, 수정신고, 조사 이력

## 4. 관련 세금과 실행

- 증여세 외 양도소득세, 취득세, 종합부동산세, 외국세 가능성
- 신고·납부 재원과 연부연납·물납 등 검토 필요성
- 계약, 금융기관 승인, 등기, 감정, 이사회 또는 주주 승인 등 선행 절차
- 신고 담당자와 최종 의사결정자

## 5. 즉시 전문가 검토 표시

다음 중 하나라도 있으면 `전문가 필수`로 표시한다: 고액, 국외재산, 비상장주식, 가업승계, 공익법인, 명의신탁 의심, 채무의 실질 불명확, 특수관계 저가·고가 거래, 소급 문서 요청, 조사 진행, 가족 분쟁.
