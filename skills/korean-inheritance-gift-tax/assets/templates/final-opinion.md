# 검토 결론

핵심 결론, 가장 중요한 전제, 최고 위험, 전문가 필수 여부를 3~7줄로 작성한다.

# 사실관계

확인된 사실, 사용자 진술, 가정, 미확인 사실을 각각 분리하고 fact/evidence ID를 연결한다.

# 증거자료 현황

수령·검토·충돌·미수령 자료와 개인정보 마스킹 상태를 요약한다.

# 세법 검토

쟁점별 법령명·조문·시행일·적용 기준일·공식 URL·확인일, 명확한 규정, 해석 필요사항, 판단을 정리한다.

# 예상 세액

입력, 산식, 중간값, 구간별·누진공제 검산, 본세, 세액공제·할증·가산세, 별도 세금, 경고, 시나리오를 표시한다.

# 대안 비교

각 방안의 총 세부담, 적용요건, 증빙, 장점, 위험, 사후관리, 추징, 2차 세금과 분쟁 영향을 비교한다.

# 신고 일정과 필요 서류

법정기한, 내부 목표일, 선행업무, 담당자, 준비자료, 상태를 체크리스트로 작성한다.

# 위험 신호

높음·중간·낮음, 원인, 증거 공백, 완화조치, 필수 전문가를 표시한다.

# 전문가 확인사항

전문가가 예/아니오 또는 구체적 수치·근거로 답할 수 있는 질문을 작성한다.

# 승인 및 미확인 사항

검토자, 승인 상태, 승인 조건, 남은 미확인 사항, 재계산 필요 여부를 표시한다.

# 출처와 기준일

출처 ID, 공식 링크, 법령 버전, 시행일, 확인일, 과세 기준일을 기재한다.
